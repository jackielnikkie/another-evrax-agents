## Jebakan (jangan diulang)

- Jangan `Set-Content`/`Out-File` untuk source (BOM/mojibake). Pakai edit tool atau `[System.IO.File]::WriteAllText($p,$t,(New-Object System.Text.UTF8Encoding($false)))`; cek BOM `EF BB BF`.
- Windows crossterm mengirim `KeyEventKind::Press` + `Release` → dispatch wajib filter `Press` (sudah + regression test).
- `cargo build`/`run` gagal `Access is denied. (os error 5)` kalau instance evrax hidup → cek `Get-Process evrax`.
- Read/`Get-Content` terpotong ~2.4 KB → window `Select-Object -Skip N -First M`.
- Jangan blind string-replace; pakai script dengan cek MISS, lalu `cargo fmt` + gate penuh.
- Name guard `scripts/check-names.ps1` memblokir `opencode`/`hermes`; contoh provider di dokumen/test = `Nimbus Go`.
- `session_id` immutable (`session-<ms>-<n>`) — jangan rename; judul tampilan di `App.titles`.
